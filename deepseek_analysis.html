二、各模块具体职责、判断逻辑、性能指标

2.1 BLDC_Controller

职责

  • 三种控制类型：COM（六步换相）、SIN（正弦波）、FOC（磁场定向控制）
  • 四种控制模式：OPEN（开环）、VLT（电压）、SPD（速度闭环）、TRQ（转矩闭环）
  • 弱磁控制/相位超前：线性插值从 FIELD_WEAK_LO 到 FIELD_WEAK_HI
  • 电流 PI 调节器（D/Q 轴）+ 速度 PI 调节器 + 反电动势观测器

判断逻辑

  • 控制模式状态机：IN_OPEN → IN_VOLTAGE_MODE → IN_SPEED_MODE → IN_TORQUE_MODE
  • 弱磁启动：目标转速 ≥ FIELD_WEAK_LO，线性增加到 FIELD_WEAK_HI
  • 电流斩波：DC 链路电流 > I_DC_MAX 时强制限幅
  • 错误检测：z_errCode 非零时触发电机禁用

2.2 Main Loop

职责

  • 每 16 个 buzzerTimer tick 执行一次控制循环
  • 调用链：readCommand() → calcAvgSpeed() → 安全检测 → 滤波 → 混控 → 输出
  • 电机使能安全检查：初始输入必须 < 50 才允许使能
  • 多级告警：温度、电池、超时、错误码

判断逻辑

  • 电机使能：enable==0 && !errCode && ABS(cmd)<50
  • 电池低压关机：batVoltage < BAT_DEAD && speedAvgAbs < 20
  • 过温关机：board_temp ≥ TEMP_POWEROFF && speedAvgAbs < 20
  • 不活动关机：inactivity_timeout_counter > INACTIVITY_TIMEOUT*60*1000/DELAY_IN_MAIN_LOOP

性能指标

每 10ms

2.4 Control

职责

  • PPM 解码：下降沿中断 + TIM2 计时
  • PWM 脉宽捕获：双通道上升/下降沿中断，互锁检测
  • Nunchuk I2C：初始化序列 + 6 字节读取 + 校验和
  • Nunchuk 状态机：CONNECTING → CONNECTED → RECONNECTING → DISCONNECTED

判断逻辑

  • PPM 帧同步：脉冲间隔 > 3000us 视为帧起始
  • PPM 有效性：每通道 [900, 2100] us
  • Nunchuk 校验：checksum==0 或 ==0x5FA 无效
  • 超时处理：500ms 无信号 → 归中值

2.6 FLW_Follow

职责

  • $FLW 协议解析：$FLW,dist_cm,angle_x10,x_cm,y_cm,status
  • P 控制器：距离误差→速度指令，角度→转向指令
  • 安全超时：无帧接收超时自动停车

判断逻辑

  • status != 1 → 停车
  • dist < TARGET → 全锁止（速度=0 且转向=0）
  • TARGET ≤ dist < TARGET+HYST → 最低速度，无转向
  • dist ≥ TARGET+HYST → 比例控制
  • |angle| < DEADZONE → 转向=0

2.9 Signal Board

职责

  • 蓝牙门控：接收 START/STOP，控制 bt_armed
  • UWB 帧转发：从 BU04 接收 $FLW，叠加避障后转发
  • TOFSense CAN 避障：三区决策，20Hz 周期发送

判断逻辑

  • 门控：bt_armed==0 → 停车帧
  • 避障优先级：闪避/围堵 > UWB 跟随 > 停车
  • 三区同时危险 → 围堵旋转脱困（交替 CW/CCW）
  • UWB 超时 500ms → 停车

2.10 TOFSense CAN

职责

  • CAN 协议解析：StdID 0x200+id，24-bit 距离，8-bit 状态，16-bit 信号强度
  • 64 像素双缓冲：位图跟踪接收状态
  • 三区汇总：左/中/右各 16 像素取最小有效距离

判断逻辑

  • 像素有效性：dis_status==0 且 signal_strength > threshold
  • 64 帧收齐：s_rx_mask == 0xFFFFFFFFFFFFFFFFULL
  • 围堵状态机：s_turn_flag 交替切换旋转方向

七、优先级

系统安全优先级（从高到低）

  1. P1 过温关机 — 立即 poweroff()
  2. P2 电池耗尽 — 立即 poweroff()
  3. P3 电机错误 — 禁用电机 + 蜂鸣
  4. P4 不活动超时 — poweroff()
  5. P5 TOF 避障（围堵/闪避） — 覆盖 UWB 指令
  6. P6 蓝牙门控 STOP — 停车帧
  7. P7 ADC 超时 — 蜂鸣
  8. P8 串口超时 — 蜂鸣
  9. P9 通用超时 — 蜂鸣
  10. P10 温度告警 — 蜂鸣
  11. P11 电池 LVL1 — 快速蜂鸣
  12. P12 电池 LVL2 — 慢速蜂鸣
  13. P13 TOF 减速 — 限制 UWB 距离
  14. P14 UWB 超时 — 停车
  15. P15 倒车蜂鸣 — 高音蜂鸣

蜂鸣告警优先级

errCode > timeoutFlgADC > timeoutFlgSerial > timeoutFlgGen
> TEMP_WARNING > BAT_LVL1 > BAT_LVL2 > BEEPS_BACKWARD

八、信号板深层逻辑

门控状态机

          START\n                STOP\n
┌──────────┐ ────────────> ┌──────────┐
│ bt_armed │               │ bt_armed │
│   = 0    │ <──────────── │   = 1    │
│ LED 灭   │    STOP\n     │ LED 亮   │
│ 发停车帧  │               │ 发跟随帧  │
└──────────┘               └──────────┘

避障叠加算法

  • AVOID_NONE：正常转发，dist=uwb_dist，angle=-uwb_angle_x10*5
  • AVOID_SLOW_DOWN：保持 UWB 角度，dist=min(uwb_dist, slow_dist)
  • AVOID_SHIFT_LEFT/RIGHT：完全覆盖，使用避障输出
  • AVOID_ROTATE_CW/CCW：完全覆盖，使用围堵参数

角度增益设计

信号板对 UWB 角度做 ×5 增益放大。电机板再除以 10 乘以 KP。
实际等效增益：5 × FLW_ANGLE_KP / 10 = 0.5 × FLW_ANGLE_KP

围堵脱困状态机

s_turn_flag=0 ──三面围堵──> s_turn_flag=1 (CCW)
s_turn_flag=1 ──三面围堵──> s_turn_flag=2 (CW)
s_turn_flag=2 ──三面围堵──> s_turn_flag=1 (CCW) ...
任何非围堵情况 ──────────> s_turn_flag=0

周期发送机制

信号板以固定 20Hz 发送 $FLW 帧（非事件驱动），停车帧也持续发送，确保电机板不会因超时误判。

九、各模块明显漏洞

BLDC_Controller

  • 严重 z_errCode 在 UWB 模式下强制清零，掩盖真实硬件故障
  • 中等 弱磁控制无温度补偿
  • 低 Simulink 自动代码不可维护

Main Loop

  • 严重 buzzerTimer 32-bit 溢出可能跳过控制周期
  • 中等 inactivity_timeout_counter 无上限保护
  • 中等 关机条件 speedAvgAbs<20 在堵转时不满足

Comms

  • 严重 errors 数组越界（声明 9 实际 10 个元素）
  • 中等 无命令注入防护
  • 低 左右参数无原子性保证

Control

  • 中等 16-bit 定时器 ~65ms 溢出与 PPM 帧周期冲突
  • 中等 Nunchuk 读取 HAL_Delay(3) 阻塞
  • 低 校验和只检查 0 和 0x5FA

EEPROM

  • 中等 Flash 写入期间掉电可能损坏数据
  • 低 无写入次数统计

FLW_Follow

  • 中等 缓冲区溢出静默丢弃数据
  • 中等 P 控制器无积分项，存在稳态误差
  • 严重 flw_last_rx 初始值 0 导致启动即超时

Util

  • 中等 input_cal_timeout uint16_t 可能溢出
  • 严重 electricBrake() ELECTRIC_BRAKE_THRES 可能除零
  • 低 checkInputType 整数除法边界误判

Signal Board

  • 中等 bt_line[16] 缓冲区过小
  • 中等 uart3_send_str 阻塞发送
  • 严重 避障/UWB 切换无平滑过渡，电机抖动
  • 中等 angle=-uwb_angle_x10*5 可能溢出

TOFSense CAN

  • 严重 s_rx_mask 无超时，像素丢失则永久阻塞
  • 中等 中断中执行浮点运算
  • 中等 s_zone 并发访问保护不完整

十、模块间配合问题

#问题涉及模块严重度影响
1 协议二义性：$FLW angle_x10 语义不同，信号板 ×5 增益 + 电机板 /10×KP Signal Board ↔ FLW_Follow 严重 参数调整需同时修改两端，调试困难
2 超时竞争：信号板 500ms + 电机板 1000ms，最坏 1500ms 无响应 Signal Board ↔ FLW_Follow 中等 紧急情况响应延迟
3 避障与跟随冲突：避障 dist_cm < TARGET 时电机板全锁止，抵消转向 Signal Board ↔ FLW_Follow 严重 避障转向失效，车辆原地不动
4 enable 竞态：主循环写、中断读，无原子保护 Main Loop ↔ BLDC_Controller 中等 电机使能状态不一致
5 Flash 写入不安全：电机运行时保存参数暂停 CPU Comms ↔ EEPROM 中等 电机短暂失控或异响
6 输入源切换无过渡：滤波器状态不重置，指令跳变 Util ↔ Control 中等 车辆突然加速或转向
7 超时标志复用冲突：UWB 模式强制清零所有超时标志 Main Loop ↔ FLW_Follow 严重 硬件故障被静默掩盖
8 数据新鲜度：TOF 更新率低于 20Hz 发送率 Signal Board ↔ TOFSense 低 避障决策基于过时数据
9 全局变量耦合：pwml/pwmr/enable 多模块直接读写 全部模块 中等 数据流难追踪，意外修改
10 中断优先级全为 0：无优先级区分 全部模块 中等 关键中断可能被非关键中断延迟
